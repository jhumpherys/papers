# The De Cock–De Moor Conjecture: Proof, Normal Form, and Indefinite Angles

Jeffrey Humpherys

* Preprint: [arXiv:2608.29479](https://arxiv.org/abs/2608.29479)
* Lean formalization: [`lean/`](lean), archived at [doi:10.5281/zenodo.23287537](https://doi.org/10.5281/zenodo.23287537)

[![Lean build](https://github.com/jhumpherys/papers/actions/workflows/decock-demoor-lean.yml/badge.svg)](https://github.com/jhumpherys/papers/actions/workflows/decock-demoor-lean.yml)

The `lean` folder contains a Lean 4 formalization, depending only on Mathlib, of the main theorem (Theorem 2.2) of the paper for real data. See [`lean/README.md`](lean/README.md) for build instructions, a table matching each result to its formal statement, and a list of the results that are not formalized.
