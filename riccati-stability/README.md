# Riccati Stability Without Auxiliary Matrices

Jeffrey Humpherys

* Preprint: [arXiv:2609.06275](https://arxiv.org/abs/2609.06275)
* Lean formalization: [`lean/`](lean), archived at [doi:10.5281/zenodo.23287150](https://doi.org/10.5281/zenodo.23287150)

[![Lean build](https://github.com/jhumpherys/papers/actions/workflows/riccati-lean.yml/badge.svg)](https://github.com/jhumpherys/papers/actions/workflows/riccati-lean.yml)

The `lean` folder contains a Lean 4 formalization, depending only on Mathlib, of the results in Sections 2 to 4 of the paper. See [`lean/README.md`](lean/README.md) for build instructions and a table matching each result to its formal statement.
